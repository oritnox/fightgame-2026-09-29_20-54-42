# P00 작업 헌법

기준: 전체 구현설계 v0.1, 로드맵 v0.1. 작업 상태: 구현용 기록, 공식 명세 등록 아님.
현재 사용자가 지정한 공개 저장소에 P00 소스와 필요한 작업 문서만 기록한다. 원본 전체 기획·개인 정보·첨부 XLSX는 자동 공개하지 않는다.

| ID | 원칙 | 확인 |
|---|---|---|
| C01 | 플레이어가 행동 가능한 상태라면 기본 입력을 다음 박자까지 대기시키지 않는다 | 입력 승인/동작 시작 로그 |
| C02 | 실제 명중·방어와 리듬 정확도를 분리한다 | 허공 정밀 입력이 피해·게이지를 만들지 않음 |
| C03 | 공개한 위협의 타격 시점을 임의로 앞당기거나 늦추지 않는다 | 예약 해시와 실행 시간 대조 |
| C04 | 자세 붕괴·사망으로 사라진 위협은 취소한다 | 없는 공격에 방어 실패 부과 금지 |

| C14 | 그래프 분기에서 가능한 경로가 없으면 검증된 중립 구절로 복구한다 | 그래프 막힘 시험 |
| C15 | 의상·체형 외형 옵션은 판정과 기본 능력치를 바꾸지 않는다 | 의상 간 충돌 결과 비교 |

## 변경과 완료

소스 작성 → 정적 검사 → 직접 모듈 시험 → 실제 Unity 연결 → 해당 인수시험 → 증거 검토를 구분한다.
C# 구문 검사는 Unity 컴파일이 아니며, 빈 Windows 빌드는 게임 완성이 아니다.
코드 전체, 실제 프로젝트 경로, 정상·실패 경로, 변경 영향, 시험 상태를 함께 기록한다.
미설치 도구/장치 때문에 검증을 못 하면 BLOCKED/NOT_RUN으로 남긴다. 과거 PASS는 현재 source hash와 다르면 재사용하지 않는다.

원본 삭제·엔진 업그레이드·자산 구매·저장 파괴·외부 전송·기본 브랜치 병합은 별도 작업이다.
정상 파일은 실패 경로에서도 보존한다. 원본 명세 v0.1은 수정하지 않는다.
이 저장소 초기 코드에 소유자가 고르지 않은 오픈소스 라이선스를 임의로 부여하지 않는다.
