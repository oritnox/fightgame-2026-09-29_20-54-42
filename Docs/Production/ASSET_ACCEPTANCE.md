# 자산 인수

모델: 성인 디자인·스케일·리그·UV·LOD·재질·의상 가림 mask·출처.
모션: 시작/끝 자세·접촉 시점·root 곡선·hit/hurt 궤적·허용 속도·source hash.
음악: 동일 원점/길이 stem·BPM/박자·source sample·전환/loop/tail·권리 근거.
UI/효과: key·배율·색 외 구분·섬광 감소·폰트 이용조건.

검사 → 격리 임포트 → 참조/hash/스케일 검사 → 실제 장면 인수 → 제품 목록 편입 순서다.
임시 자산 통과는 최종 자산의 증거가 아니다. 의상은 전투 판정을 변경하지 않는다.
P00에는 최종 자산 제작·구매·대량 반입을 하지 않는다.
