# 외부 자산 출처 대장

이번 이식으로 새 반입한 제3자 모델·모션·음악·폰트·유료 에셋: 없음.
사용자가 만든 Unity 초기 템플릿 자산과 manifest/lock은 이미 저장소에 있으며 그대로 유지한다. 패키지의 실제 다운로드·컴파일 성공은 이 실행 환경에서 확인하지 않았다.
원본 명세는 사용자 제공이며 hash 색인만 기록한다.

| ID | 종류 | 출처·취득일 | 정확한 버전/hash | 원본/런타임 경로 | 이용조건 근거 | 상업사용·수정·배포·고지 | 검토자/상태 |
|---|---|---|---|---|---|---|---|

자산 도입 시 임시/최종을 분리하고 공식 이용조건의 확인 날짜와 근거를 보관한다.
권리 미확인은 제품 후보 제외, 구매·라이선스 동의·원본 공개는 별도 권한으로 수행한다.
공개 저장소에 원본 라이선스 파일·폰트 파일·구매 영수증을 자동 업로드하지 않는다.
