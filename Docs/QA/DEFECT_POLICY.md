# 작업 상태와 결함

TODO → READY(선행·환경 확보) → IN_PROGRESS → REVIEW(증거 확보) → DONE.
어느 상태에서도 환경/자산 부족은 BLOCKED, 필수 결함은 작업 재개로 전환한다. 선행 미충족 준비 산출물은 DONE이 아니다.
시험 NOT_RUN은 아직 실행하지 않음, BLOCKED는 실행에 필요한 조건이 없음, FAIL은 실행 결과 불일치다.

P0: 데이터 손실·비밀 노출·정상 파일 파괴. 즉시 멈추고 원본 보존.
P1: 진행 불가·잘못된 피해·게이트 우회·가짜 PASS. 다음 단계 진입 금지.
P2: 동작 오류·읽기 어려움·성능 목표 초과. 재현 조건과 수정 검증 기록.
P3: 기능에 영향 없는 표현 결함. 범위와 인수 시점 기록.
결함에는 ID·scope·재현·기대/실제·build/source/content hash·영향 파일·담당·수정 증거를 기록한다.
